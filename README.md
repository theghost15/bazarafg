# بازار — النسخة المطورة

هذه النسخة تتضمن:
- واجهة متجر مطورة وديناميكية في `index.html`.
- دعم العربية ودري والبشتو والفارسية والإنجليزية.
- لوحة إدارة ديناميكية بقائمة جانبية قابلة للطي والتوسيع.
- إدارة العملاء: إنشاء، تعديل، حذف سجل العميل، وملف العميل والطلبات.
- إدارة البائعين: إنشاء حساب بائع، تعديل البيانات، اعتماد/إلغاء الاعتماد، تفعيل/إيقاف.
- حماية صلاحيات الإدارة عبر Supabase/RLS وRPC.
- دعم SUPER ADMIN الموجود في النظام.

## SQL الجديد
شغّل `ADMIN_PEOPLE_CRUD.sql` مرة واحدة في Supabase SQL Editor بعد إنشاء الجداول/الترحيلات الأساسية للمشروع.

لا تضع service_role key أو أي كلمة مرور داخل ملفات الواجهة.
